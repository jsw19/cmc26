## Generation prompt

Use case: logo-brand. Create a polished logo concept presentation for CheckMyCar, a private on-device vehicle photo inspection app. One coherent design, scan + car. Flat vector-style graphic, exceptionally clean geometry, bold consistent rounded strokes. Main symbol is a simplified front-facing car, recognizable roof/windshield and two simple headlights, enclosed by two diagonally opposed scanning corner brackets. Car in warm white, scan brackets bright teal #2DD4BF, background deep navy #0B1426. No checkmark, shield, wrench, gradients, glow, 3D or photographic elements. Make the mark distinctive, balanced and legible at small app-icon size; minimize details. Square presentation board with generous negative space: upper two thirds features a large navy rounded-square app icon on off-white background, showing this symbol. Lower third shows a smaller identical symbol beside the exact wordmark 'CheckMyCar' in a modern rounded yet confident sans serif, dark navy, on off-white. Small bottom-right monochrome navy rendition of same symbol demonstrates one-color use. Only text is 'CheckMyCar'; no extra captions or taglines. Professional restrained identity design, crisp edges. This is a concept preview, not a screenshot of an app.
